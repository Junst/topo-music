What hides musical geometry?

Audio encoders demonstrably encode musical key. Whether that structure shows up in the distances a downstream model actually uses is a separate question, and the answer depends on two things that are easy to confuse. Move the controls to watch each one.

MECHANISM 1Sample-limited masking

Nuisance that varies independently of the class — production, instrumentation, subgenre — cancels in a mean. So it hides structure from any estimate built on few examples, and more examples reveal it. More audio per example does almost nothing.

MECHANISM 2Metric masking

Nuisance that is a function of the class cannot average away — on isolated notes, register and spectral envelope are determined by pitch, so every pitch centroid keeps them. Averaging never exposes octave equivalence. A projection does, and the one used here was fitted only on GiantSteps track keys: no notes, no NSynth.

The control block is what makes a null readable. Orthogonal per-key codes decode key better than any real representation, with classes equidistant by construction — and show no fifths structure anywhere. So the readout column is not something an accurate key classifier produces on its own.
